# Магазин обуви – информационная система



## Описание проекта

Информационная система для магазина по продаже обуви. Реализована на **Python (FastAPI)** с использованием **PostgreSQL**, контейнеризация через **Docker**. 
Приложение позволяет:

- Авторизоваться с разными ролями (администратор, менеджер, клиент, гость)
- Просматривать товары с подсветкой строк в зависимости от скидки и наличия
- Для менеджера/администратора: поиск, сортировка и фильтрация товаров в реальном времени
- Управлять товарами и заказами (CRUD) – только для администратора
- Загружать изображения товаров с автоматическим изменением размера (300×200)
- Удалять товары только если они не присутствуют в заказах

## Технологии

- Python 3.9
- FastAPI
- PostgreSQL 14
- SQLAlchemy (ORM)
- Jinja2 (шаблонизатор)
- Docker / Docker Compose
- JWT (аутентификация)
- Passlib (хэширование паролей)
